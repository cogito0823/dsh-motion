# Dark Editorial · 暗场编辑

> 近黑蓝底、暖白墨色、灰蓝结构线、单一琥珀强调色。  
> 数学 / 数据 / 概念类短片优先使用双栏编辑版式，运动只做“生长、旋转、停住”。

## 1. 定位

**适合**

- 数学、物理、数据、工程概念的解释型短片；
- 8–30 秒、有一个明确关系或结论的内容；
- 需要“冷静、可信、像一页科学出版物”的语气。

**不适合**

- 角色叙事、搞笑、快节奏混剪；
- 需要高饱和情绪的商业广告；
- 多主体、多场景切换的复杂故事。

## 2. 语法

这套风格是两种已验证语言的混合：

| 来源 | 取什么 | 不取什么 |
|---|---|---|
| 编辑排版 | 网格、字阶、单一强调色、双栏论证 | 杂志封面式的巨大英文标题 |
| 暗场发光 | 近黑底、细线、轨迹、颗粒、暗角 | 霓虹、辉光球、镜头光晕 |

核心原则只有五条：

1. **一个结论，一条动线。** 全片只围绕一个变换或一个关系。
2. **结构灰、知识白、运动琥珀。** 颜色不是装饰，是语义。
3. **先有线，再有面。** 坐标轴和单位圆是细线，只有运动与结论用强调色。
4. **留白是节奏。** 结论出现前，右栏可以空着。
5. **运动只做生长、旋转、停住。** 不弹跳、不缩放冲击、不反复进出。

## 3. Tokens

`tokens.json` 是颜色、字体、运动时间表与音频参数的可复用数值来源；下表是它的可读版本。版面坐标与组件配方以本文件为准，`tokens.json` 里的 `layout` 只保留参考实现的最小锚点。

### 颜色

| Token | 值 | 用途 |
|---|---|---|
| `ground` | `#0B0F16` | 底色，近黑蓝，不用纯黑 |
| `ink` | `#EFEAE0` | 标题、公式主体，暖白 |
| `muted` | `#8791A3` | 辅助标签、说明 |
| `axis` | `#344054` | 坐标轴、分隔线、细规则 |
| `accent` | `#E3A857` | 运动、轨迹、最终结论 |
| `circle` | `#6E7C93` | 单位圆等结构线 |
| `glow_core` | `#151A24` | 背景径向渐变的中心色 |

规则：

- 全片只允许 **一个强调色**；本风格固定为琥珀 `#E3A857`。
- 琥珀只给“正在动的东西”和“最终答案”。在 `e^{iπ}+1=0` 里，只有 `0` 是琥珀。
- 不用纯黑 `#000000`；不用高饱和青、紫、荧光绿。

### 字体

| 层级 | 字体 | 字号 | 用法 |
|---|---|---|---|
| 中文标题 | Noto Sans CJK SC Bold | 64 | 片名，最多 6 字 |
| 中文正文 | Noto Sans CJK SC Regular | 24–26 | 副标题、注解 |
| 数学 | New Computer Modern | 80 | 主公式 |
| 小标签 | Noto Sans CJK SC | 18 | “一般形式”“特例” |
| 坐标标签 | serif italic | 21 | `Re`、`Im`、`θ` |
| 页脚 | sans-serif | 17 | 页脚标记，字距可拉开 |

规则：

- 不用 Inter / Space Grotesk / 系统默认无衬线做标题。
- 中文标题和数学公式是两种语言，允许字体对比，但字号层级不超过 3 级。
- 英文只作小号辅助标签，不做大标题。

### 版面

16:9 的 frame 是 **14.222 × 8.0** 场景单位（1920×1080）。

| 元素 | 位置 / 尺寸 |
|---|---|
| 标题块 | 左边缘 `x=-6.55`，块中心约 `y=2.62` |
| 标题下细线 | `y=1.62`，宽 1.72，琥珀 55% |
| 单位圆 | 圆心 `(-2.50, -0.60)`，半径 `2.05` |
| 坐标轴 | 水平 ±2.62，垂直 −2.50 / +2.62 |
| 竖向分隔线 | `x=0.82`，从 `y=3.40` 到 `y=-2.92` |
| 右栏中心 | `x=4.00` |
| 一般形式 | `y=2.50` |
| 特例细线 | `y=1.76`，从 `x=1.32` 到 `x=6.68` |
| 主公式 | `y=0.64` |
| 注解 | `y=-0.55` |
| 常数列表 | `y=-1.12` |
| 页脚 | 右下，`y=-2.70` |

示意：

```text
┌──────────────────────────────────────────────┐
│ 数学速写 / 001                 一般形式       │
│ 欧拉公式                  e^{iθ}=cosθ+isinθ  │
│ 单位圆上的半圈          ───── 特例 ─────      │
│                                              │
│        ◯ 单位圆              e^{iπ}+1=0      │
│                                              │
│                          五个常数，一个等式   │
└──────────────────────────────────────────────┘
```

留白：

- 四周约 0.45–0.6 单位；
- 任何文字不与圆、轴、分隔线相交；
- 右栏在结论出现前可以空着，这是节奏，不是失误。

### 线宽

|---|---|---|
| 坐标轴 | 1.4 | 1.0 |
| 单位圆 | 2.2 | 0.90 |
| 分隔线 | 1.0 | 0.75 |
| 特例细线 | 1.2 | 1.0 |
| 向量 | 4.2 | 1.0 |
| 轨迹 | 4.6 | 0.95 |
| 轨迹辉光 | 15 | 0.10 |

## 4. 组件配方

### 背景

不要用两层半透明圆做光晕：边缘会露出硬圆盘，暗部还会 banding。

推荐做法：

- 生成一张 1920×1080 的径向渐变图；
- 以单位圆圆心为中心，高斯衰减半径 3.4 单位；
- 边缘 `#0B0F16`，中心 `#151A24`；
- 每个通道加 ±1 的随机抖动，压住色带；
- 用 `ImageMobject` 铺满画面。

参考实现：[theme.py](theme.py) 的 `backdrop()`。

### 坐标与单位圆

- 坐标轴用 `Arrow`，`stroke_color=axis`，`stroke_width=1.4`，tip 长度 0.13。
- `Re` / `Im` 用衬线斜体 21，位置在轴端外侧。
- 单位圆用 `Circle`，`circle` 色，线宽 2.2，透明度 0.90。
- **不要加虚线外轨道**：本片预览里，虚线外轨道读成了一个圆角方框的轮廓，和“精确的圆”冲突。

### 向量与轨迹

- 向量从圆心指向圆周，琥珀色，线宽 4.2；
- 在下面叠一条 13 宽、11% 透明度的辉光副本；
- 端点用 0.085 的白点和 0.16 的琥珀环；
- 轨迹用 `TracedPath`：15 宽 10% 的辉光 + 4.6 宽 95% 的主线；
- 角度弧半径 0.56，`θ` 标签 25，跟随弧的中间角。

参考实现：[episodes/euler/scene.py](https://github.com/cogito0823/dsh-motion/blob/main/episodes/euler/scene.py) 的 `arm_glow()` 与 `trail_glow`。

### 右栏

- 小标签：“一般形式”“特例”，18，muted；
- 一般形式：36，ink；
- 特例细线：横贯右栏，上面左“特例”、右“θ = π”；
- 主公式：80，ink，只有最终的 `0` 用 accent；
- 注解：26，ink 85%；
- 常数列表：22，muted 80%，用中点分隔；
- 页脚：17，muted 65%。

### 标题

- Kicker：21，accent，例如“数学速写 / 001”；
- 标题：64，Noto Sans CJK SC Bold；
- 副标题：26，muted；
- 下方细线：1.4，accent 55%。

## 5. 运动

### 时间表（10 秒）

| 时间 | 动作 | 时长 |
|---|---|---|
| 0.0–1.2 | 标题写入；右栏一般形式淡入 | 1.2 |
| 1.2–2.2 | 坐标轴、单位圆生长 | 1.0 |
| 2.2–2.9 | 向量从原点长出 | 0.7 |
| 2.9–6.2 | 逆时针 0→π，轨迹同步 | 3.3 |
| 6.2–6.9 | −1 处脉冲；一般形式压暗 | 0.7 |
| 6.9–7.5 | “特例 / θ=π”细线出现 | 0.6 |
| 7.5–9.0 | 主公式写入；注解淡入 | 1.5 |
| 9.0–10.0 | 停留 | 1.0 |

规则：

- 60 fps；30 fps 可以，但细线和轨迹会差一些；
- 旋转用 `smooth`，不要 `linear`，也不要弹跳；
- 同一时刻只有一个“琥珀运动”；
- 片尾至少留 1.0 秒读公式；
- 不要做镜头推拉；画面稳定比炫技重要。

### 12 秒 / 15 秒怎么办

- 优先加长“旋转”和“停留”，不要加新画面；
- 10 秒结构可以整体拉伸 1.2–1.5 倍；
- 不要为了填时长加卡片、加音效、加转场。

## 6. 声音

参考实现：[episodes/euler/make_audio.py](https://github.com/cogito0823/dsh-motion/blob/main/episodes/euler/make_audio.py)。

- A 大调长音：A2 110 / E3 164.81 / A3 220 / C#4 277.18 / E4 329.63；
- 极轻的低通空气噪声；
- 55 Hz 低频 swell，在结论前托一下；
- 880 Hz 弱钟放在公式开始写入前 0.15 秒（本片 7.35 秒）；
- 无鼓点、无 riser、无 whoosh；
- 淡入 1.35 秒，淡出 1.45 秒；
- 目标 −16 LUFS，真峰值 ≤ −2 dBTP。

## 7. Do / Don't

**Do**

- 先写分集 `DESIGN.md`，再写场景；
- 公式先过 `formula_check`；
- 用 `manimgx inspect` 检查压字、出画、小字号；
- 用 `motion_probe` 检查空镜；
- 让右栏有呼吸感，结论出现前可以空。

**Don't**

- 不用高饱和霓虹、渐变球、发光滤镜、投影；
- 不用纯黑底；
- 不用超过一个强调色；
- 不把文字堆成卡片；
- 不用 Inter / Space Grotesk 做标题；
- 不加虚线外轨道；
- 不在画面上烧录字幕条；需要字幕时放在 composition 层。

## 8. 竖版适配

以下为建议，**尚未出片验证**；做 9:16 时需要重新跑 `manimgx inspect`。

- 注解 `y≈-4.1`，页脚 `y≈-6.6`；
- 左右留白至少 0.6 单位。
