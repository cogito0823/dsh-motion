# 导数 · 割线如何变成切线

10 秒数学短片。`f(x) = x²/2` 上取定点 `P(1, 1/2)`，另一个点 `Q` 沿曲线滑向 `P`；
割线的斜率随之从 `0.10` 爬到 `1.00`，落定成切线，也就是 `f'(1) = 1`。

本片是 [dark-editorial@1.0.0](../../styles/dark-editorial/STYLE.md) 系列的第二支；本文件只记录本片的局部决定。

## Do

- 暗场，近黑蓝底 `#0B0F16`；坐标轴是灰蓝细线，曲线是暖白细线。
- 唯一的运动色是琥珀：只给滑动的 `Q`、落定的切线、以及答案里的 `1`。
- 运动只有三种：生长（轴、曲线）、滑动（`Q`）、旋转（割线）。到位即停。
- 切线出现时，割线精确重合于它——观众看到的是“同一根线换了身份”，不是另一根线。
- 公式先过 `formula_check`，再上屏。

## Don't

- 不用高饱和霓虹、渐变球、发光滤镜、投影。
- 不做 `Δx/Δy` 辅助三角：割线本身很平，三角的两条边会和它挤在一起，读不清。
- 不给每句话配卡片；全片只有标题、定义、一个结果、一行注解。
- 不在画面上烧录字幕条；本片无旁白。

## 版面

- 左栏：标题块在左上；坐标系原点 `(-3.90, -2.30)`，比例 `1.30` 场景单位 / 数学单位，
  `x ∈ [-2.04, 2.30]`，`y ∈ [0, 2.75]`。曲线与切线都裁切在这个窗口内。
- 右栏：`x = 4.00`。定义在上，`本例` 分隔线在中，结果 `f'(1) = 1` 在中下。
- 竖向分隔线 `x = 0.82`；标题左边缘与坐标轴左端都对齐 `x = -6.55`。
- `P` 的标签放在点的右下侧，避开切线、割线与曲线三条边。

## 数学

| 式子 | 用途 | 校验 |
|---|---|---|
| `f(x) = x²/2` | 本片的函数 | — |
| `f'(x) = x` | 求导结果 | `diff(x**2/2, x) == x` |
| `f'(1) = 1` | 结论 | `diff(x**2/2, x).subs(x, 1) == 1` |
| `(f(1) − f(q)) / (1 − q) = (1 + q)/2` | 割线斜率，`q = 1` 时取极限不除零 | 恒等 |
